T08「实现公告发布、修改与关闭」交付与验证说明
日期：2026-10-22（Asia/Macau）

实施负责人：庄薇琪；复核负责人：刘昱彤。当前为实现完成、待复核。

一、已实现
1. 发布 Lost / Found 公告：受控分类/区域、标题5–80字、描述20–1000字、日期不得晚于澳门当天，可标记约略日期。
2. 可选0–3张真实 JPEG/PNG 图片，每张不超过5MB。解码后重新编码以去除原始EXIF/GPS及文件名；最长边缩至2048，拒绝过大像素图以保护解码资源。
3. 仅登录作者可修改或关闭自己的公告，服务端检查权限；支持稳定ID与链接、递增版本、变更历史、审计记录。
4. Pending/Held/Approved活动认领或有效预约存在时锁定修改与归档，覆盖found及其关联lost公告。Closed/Returned保持只读；Closed仅表示归档，不等于已归还。
5. 版本冲突返回409，界面保留未保存草稿供比较；同一请求重试使用幂等键，数据库将公告、照片、历史及事件作为同一事务保存。
6. 关闭后退出可用列表，原链接、当前图片及历史保留；隐藏公告及照片对普通会话不可访问。

三、启动与检查
解压完整交付包，进入 app 文件夹，双击“启动T08.command”；也可在该目录执行：
java -jar campus-lost-found-0.1.0.jar
启动后打开 http://127.0.0.1:8080/app/ 。账号alice或bob，密码均为campus-demo-2026（虚构本地账号）。
若8080占用，可加参数 --server.port=8081，再打开对应端口。
保留同目录data文件夹可保留本地数据；按Ctrl+C停止。交付包不包含本次演示数据库，首次启动为空。
源码见 source/backend；从该目录执行 mvn clean package 可重建并运行测试，首次构建需要下载依赖。
已验证本机JDK25；未单独验证JDK21运行环境。程序仅绑定本机地址，未部署网络后端。
